# 화면/UI 상세 스펙

## 화면별 상세(UI 스펙)

### 공통 레이아웃

- 상단: SearchBar(고정) + 현재 진행 단계(Progress)
- 좌측(또는 하단): 카테고리 네비게이션(현재 선택 상태 표시)
- 우측: 주요 콘텐츠(리스트/3D/요약)
- 하단: 호환성 메시지 바(경고/오류)

### V-03 PartListView

- 필수 컴포넌트:
    - 정렬 드롭다운
    - 태그 필터 패널(칩 + AND/OR 토글)
    - 리스트(가상화)
- 리스트 카드:
    - 썸네일 120x120
    - 이름(2줄), 가격, 핵심 스펙(2줄)
    - 상태 뱃지: “재고없음”, “추천”, “호환성 경고”
- 빈 상태:
    - “조건을 변경해보세요” + 인기 태그

### V-03-2 SearchResultView

- 검색 조건 요약 바:
    - 키워드, 선택 태그, 카테고리(선택 시)
    - “초기화” 버튼
- 결과 리스트는 PartListView와 동일 렌더러 재사용

### V-05 Viewer3DView

- 좌측: 현재 선택 부품 리스트(클릭 시 하이라이트)
- 우측: 3D 뷰
- 오버레이 버튼:
    - 리셋, 폭발도(확장), 레이어 토글(확장)
- 경고 표시:
    - 오류 부품이 있을 때 상단 배너 + “자세히” → 메시지 목록

### V-06 EstimateSummaryView

- 표:
    - 카테고리 | 제품명 | 가격 | 삭제/변경
- 하단:
    - 합계/세금/할인
    - 소비전력/권장 PSU
    - 호환성 상태(OK/경고/불가)
- CTA:
    - 저장/불러오기/다음

## 내비게이션 규칙

- “뒤로”는 항상 이전 화면으로(결제 중엔 제한)
- 결제 승인 중에는 화면 전환/종료 차단(취소 버튼만 허용)
- 전역 검색 실행 시:
    - 현재 화면 상태 유지
    - 결과 화면에서 선택 후 원래 화면 복귀 옵션 제공(토글)

## UX 예외 처리

- 네트워크 끊김:
    - 상단에 “오프라인” 배너
    - 결제/주문 CTA 비활성화 + 안내
- 재고 0:
    - 선택/결제 불가(대체 추천 노출)
- 호환성 “불가”:
    - 결제 단계 진입 차단(설정 가능)
