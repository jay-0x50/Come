# 요구사항 상세 (MVP 스펙)

## 범위

- 대상: WPF(.NET 8) 키오스크 앱 + 로컬 캐시(SQLite) + 원격 상품/주문 API 연동
- 제외(초기): AR, 회원 로그인, AI 자동견적(확장 단계)

## 공통 정의

### 용어

- “부품(Part)”: CPU/메인보드/RAM/GPU/스토리지/파워/케이스/쿨러
- “견적(Build)”: 사용자가 선택한 부품 조합 + 가격/전력/호환 결과
- “태그(Tag)”: 부품군/규격/용도 분류 문자열(예: CPU, DDR5, 게이밍)

### 화면 공통 규격

- 해상도: 1920x1080 기준(스케일링 지원)
- 입력: 터치 우선(멀티터치 핀치 줌), 마우스 보조
- 최소 터치 타겟: 48x48px
- 전체 화면 고정, 작업 전환/종료 방지(키오스크 모드)
- 유휴 타임아웃: 60초(설정 가능) → AttractView로 복귀, 진행 데이터 초기화

### 공통 상태 저장

- 임시 상태: 앱 메모리(ViewModel 상태)
- 지속 저장(선택): 로컬 SQLite에 “최근 견적 10개” 저장/불러오기
- 네트워크 단절 시:
    - 부품 목록/가격은 “마지막 동기화 시점” 기준 로컬 캐시로 조회
    - 결제/주문은 온라인 필수(오프라인 안내 화면)

## 기능 요구사항(구체)

### 1) Attract Mode (V-00)

- 유휴 진입 조건: 마지막 입력 이후 `IdleTimeoutSec` 경과
- 노출: 프로모션 슬라이드(이미지/영상), “화면을 터치하세요”
- 터치 시: MainMenuView로 이동
- 관리자 단축 진입: 화면 모서리 5회 탭(또는 비밀 제스처) → AdminLoginView

### 2) 메인 메뉴 (V-01)

- 버튼: “시작하기(직접 조립)”, “사전 구성 세트(확장)”
- 시작하기 선택 시: CategorySelectView

### 3) 카테고리 선택 (V-02)

- 카테고리: CPU/메인보드/RAM/GPU/SSD·HDD/파워/케이스/쿨러
- 각 카테고리 카드에 표시:
    - 선택 여부(체크)
    - 현재 선택된 부품 이름/가격(선택된 경우)
- 카테고리 선택 시: PartListView(해당 카테고리)

### 4) 부품 리스트 (V-03) + 검색바 (V-03-1)

- 리스트 아이템 표시: 이미지, 제품명, 제조사, 주요 스펙 2~3줄, 가격, 재고 상태
- 아이템 탭:
    - PartDetailPopup 열기
- “견적에 추가”:
    - PartDetailPopup에서 확정 시 BuildConfiguration에 반영
    - 기존 선택이 있으면 교체(confirm 옵션)
- 정렬(토글/드롭다운):
    - 가격 낮은순/높은순
    - 인기순(서버 제공 없으면 임시로 판매지수/조회수 컬럼 기반)
    - 성능순(벤치마크 점수 컬럼 기반)
- 페이징/가상화:
    - 대용량 목록 대비(필수) → VirtualizingStackPanel 사용

#### 검색바 요구사항(전역)

- 상단 고정(Global Search Bar)로 모든 화면에서 접근 가능:
    - 최소: CategorySelect/PartList/SearchResult/Viewer3D/EstimateSummary
    - 결제/배송 입력 화면에서는 가시성 옵션(오조작 방지) 제공
- 입력 동작:
    - 디바운스 300ms
    - 자동완성 10개 노출
    - Enter 또는 돋보기 클릭 시 SearchResultView로 이동
- 검색 옵션:
    - 키워드(제품명/제조사) LIKE
    - 초성 검색(한글) 지원
    - 오타/유사어: Levenshtein 또는 FTS5 기반(둘 중 1개 선택)
- 태그 필터:
    - 다중 선택
    - AND/OR 토글(기본 AND)
    - 선택된 태그는 칩으로 표시, X로 개별 해제
- “검색 결과 없음”:
    - 유사 키워드 제안(초성/부분일치)
    - 인기 태그/인기 부품 추천(임시 로직 가능)

### 5) 부품 상세 팝업 (V-04)

- 표시:
    - 제품명/이미지/가격/재고
    - 스펙 테이블(카테고리별)
    - 소비전력(W) (가능하면)
    - 태그
- 버튼:
    - “견적에 추가(선택)”
    - “닫기”
- 추가 시 즉시 호환성 검증 및 결과 토스트 표시

### 6) 호환성 검증(실시간)

- 트리거:
    - 부품 추가/교체/삭제 시
- 결과:
    - `IsCompatible` bool
    - `CompatibilityMessages` 리스트(카테고리별)
- 최소 규칙(MVP):
    1. CPU 소켓 ↔ 메인보드 소켓
    2. RAM DDR4/DDR5 ↔ 메인보드 지원
    3. 메인보드 폼팩터 ↔ 케이스 지원
    4. GPU 길이 ↔ 케이스 허용 길이
    5. 쿨러 높이 ↔ 케이스 허용 높이
    6. 전력 합산 + 여유율(20%) ↔ PSU 정격
- UI 반영:
    - PartList/Viewer3D에서 문제 부품 빨간 테두리 + 경고 아이콘
    - 메시지는 하단 패널 또는 팝업으로 노출(최대 5개, 더보기)

### 7) 3D 뷰어 (V-05)

- 기본:
    - 회전(드래그), 줌(핀치/휠), 리셋 버튼
- 조립 애니메이션:
    - 케이스 → 파워 → 메인보드 → CPU → 쿨러 → RAM → GPU → 스토리지
- 부품 선택 상태:
    - 미선택 파츠는 고스트(반투명)로 위치 표시
- 하이라이트:
    - 부품 탭 시 emissive/outline 하이라이트 + 제품명 툴팁
    - 호환성 오류 부품은 빨간 하이라이트 우선
- 성능:
    - 최소 30fps 목표
    - LOD 지원(필수)
    - glTF(.glb) 권장, 텍스처 압축(KTX2 등) 검토

### 8) 견적 요약 (V-06)

- 표시:
    - 선택 부품 목록(카테고리별) + 가격
    - 합계/부가세/할인(있다면)
    - 추정 소비전력, 권장 PSU
    - 호환성 결과(OK/경고/불가)
- 버튼:
    - “저장”(로컬)
    - “불러오기”(로컬)
    - “배송지 입력으로”(호환성 불가 시 이동 제한 옵션)

### 9) 배송지 입력 (V-07)

- 필드:
    - 이름, 휴대폰, 주소(우편번호 검색 API 선택), 상세주소
- 유효성:
    - 필수값, 전화번호 형식
- 다음: PaymentView

### 10) 결제 (V-08)

- 결제 수단:
    - 카드(IC 리더기)
    - QR 간편결제(카카오/네이버 등)
- 프로세스:
    1. 결제 요청 생성
    2. 승인 대기(최대 60초)
    3. 성공/실패 분기
- 실패:
    - 재시도
    - 취소(이전 화면)
- 보안:
    - 결제 정보 로컬 저장 금지(PG 토큰화만 저장)

### 11) 주문 완료 (V-09)

- 표시:
    - 주문번호, 결제 결과, 배송 안내
- 영수증 출력:
    - ESC/POS 프린터
    - 실패 시 재출력 버튼 + 관리자 로그

### 12) 관리자 모드 (V-10~11)

- 로그인:
    - PIN 또는 계정(로컬) 방식
    - 5회 실패 시 5분 잠금
- 기능(MVP):
    - 부품 동기화(서버 → 로컬 캐시)
    - 가격/재고 조회(편집은 서버 권장)
    - 로그 조회/내보내기
    - 설정(IdleTimeoutSec, 서버 URL, 프린터 설정)

## 수용 기준(Acceptance Criteria) 요약

- 검색: 키워드+태그 조합으로 결과가 300ms~1s 내 갱신(로컬 캐시 기준)
- 호환성: 부품 교체 즉시(<=300ms) 결과 갱신
- 뷰어: 기본 조작(회전/줌/부품 하이라이트) 동작, 30fps 근접 유지
- 결제: 성공 시 주문 생성 및 영수증 출력까지 완료
