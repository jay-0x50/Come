# 개발 태스크 체크리스트

## 개발 태스크(체크리스트)

### Phase 1: 골격/인프라

- [ ]  솔루션/프로젝트 생성(.NET 8, WPF)
- [ ]  DI 구성(Microsoft.Extensions.DependencyInjection)
- [ ]  MVVM Toolkit 도입(ObservableObject, RelayCommand)
- [ ]  NavigationService(화면 전환) 구현
- [ ]  앱 설정(AppSettings) 저장/로드
- [ ]  키오스크 전체화면 + 종료 방지(가능 범위) 적용
- [ ]  IdleTimer 서비스 구현(유휴 시 AttractView로 복귀)

### Phase 2: 데이터/검색

- [ ]  EF Core + SQLite 설정, 마이그레이션
- [ ]  Parts/Tags/PartTags 스키마 구현
- [ ]  PartRepository(로컬 캐시) 구현
- [ ]  서버 API 클라이언트(HttpClient) 구현
- [ ]  동기화 서비스(증분/전체) 구현
- [ ]  SearchService: 키워드+태그+정렬 구현
- [ ]  초성 검색 구현
- [ ]  유사어/오타 허용(FTS5 또는 Levenshtein) 구현
- [ ]  SearchBarView(UserControl) + 전역 배치

### Phase 3: 호환성/견적

- [ ]  BuildConfiguration 모델 + 계산(합계/전력)
- [ ]  CompatibilityService 규칙 1~6 구현
- [ ]  UI 경고 표시(리스트/뷰어/요약)

### Phase 4: 3D 뷰어

- [ ]  3D 프레임워크 선정/PoC(HelixToolkit 등)
- [ ]  glTF 로딩 파이프라인
- [ ]  파츠별 위치/피벗 정의
- [ ]  조립 애니메이션(순서 기반)
- [ ]  하이라이트/선택 상호작용
- [ ]  LOD/성능 튜닝(필수)

### Phase 5: 주문/결제/출력

- [ ]  배송지 입력 폼 + 검증
- [ ]  주문 생성 API 연동
- [ ]  PG SDK 연동(카드/QR)
- [ ]  결제 타임아웃/취소/재시도 처리
- [ ]  영수증 출력(ESC/POS) + 오류 처리
- [ ]  주문 완료 화면

### Phase 6: 관리자

- [ ]  AdminLogin(PIN) + 잠금 정책
- [ ]  AdminDashboard(동기화/설정/로그)
- [ ]  로그 내보내기

### Phase 7: QA/배포

- [ ]  터치 실기기 테스트
- [ ]  성능 측정(30fps, 300ms 전환)
- [ ]  장애 시나리오 테스트(오프라인/프린터/결제 실패)
- [ ]  MSIX 패키징/키오스크 배포 가이드

## Definition of Done(요약)

- 크래시 없이 주요 플로우(선택→검증→요약→배송→결제→완료) 1회 완주
- 로그/에러 메시지가 사용자 친화적으로 노출
- 관리자에서 동기화/설정 변경 가능
