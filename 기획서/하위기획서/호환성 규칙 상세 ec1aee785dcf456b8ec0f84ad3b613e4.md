# 호환성 규칙 상세

## 호환성 규칙 상세(구현 가이드)

### 입력

- SelectedParts: Dictionary<Category, Part>
- 각 Part는 SpecJson 파싱 가능한 DTO로 변환

### 출력

- IsCompatible: bool
- Messages: List<CompatibilityMessage>
    - Category (CPU/Mainboard/...)
    - Severity (Info/Warning/Error)
    - Code (예: SOCKET_MISMATCH)
    - Text (표시 문구)

### 규칙 목록(MVP)

1. CPU 소켓
- 조건: Cpu.Socket == Mainboard.Socket
- 실패:
    - Severity: Error
    - Code: SOCKET_MISMATCH
    - Text: “CPU 소켓과 메인보드 소켓이 일치하지 않습니다.”
1. RAM 타입
- 조건: Ram.RamType == Mainboard.RamType
- 실패: Error / RAMTYPE_MISMATCH
1. 폼팩터
- 조건: Mainboard.FormFactor in Case.SupportedFormFactors
- 실패: Error / FORMFACTOR_NOT_SUPPORTED
1. GPU 길이
- 조건: Gpu.LengthMm <= Case.MaxGpuLengthMm
- 길이 정보 없으면:
    - Warning / GPU_LENGTH_UNKNOWN
1. 쿨러 높이
- 조건: Cooler.HeightMm <= Case.MaxCoolerHeightMm
- 높이 정보 없으면 Warning
1. PSU 용량
- totalPower = Sum(SelectedParts.PowerConsumptionW ?? fallback)
- required = ceil(totalPower * 1.2)
- 조건: Psu.Wattage >= required
- PSU 미선택이면:
    - Warning / PSU_NOT_SELECTED

### Fallback 소비전력(임시)

- CPU: 105W
- GPU: 250W
- Mainboard: 50W
- RAM: 10W(키트)
- Storage: 10W
- Cooler: 10W
- Case: 5W

### 성능/호출 전략

- 부품 선택 이벤트마다 전체 재평가(간단 규칙이므로 O(n))
- ViewModel에서 결과를 캐시하고 UI 바인딩

### UI 매핑

- Error가 1개라도 있으면 IsCompatible=false
- Warning만 있으면 IsCompatible=true, 경고 배너 노출
