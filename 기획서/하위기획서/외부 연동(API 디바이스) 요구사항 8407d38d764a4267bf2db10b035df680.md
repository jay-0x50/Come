# 외부 연동(API/디바이스) 요구사항

## 외부 연동(API/디바이스) 요구사항

### 1) 상품/재고/가격 API(서버)

- 인증: API Key 또는 OAuth(선택)
- 기본 엔드포인트(예시):
    - GET /parts?category=&q=&tags=&sort=&page=
    - GET /parts/{id}
    - GET /tags
    - POST /orders
    - GET /orders/{orderId}
- 응답:
    - Part: Parts 스키마 + Tags[], BenchmarkScore, PopularityScore(선택)
    - Order: 주문 생성 결과(OrderId, Status, PaymentRedirect/Token)
- 동기화:
    - 앱 시작 시 “최근 업데이트 이후 변경분” 증분 동기화
    - 관리자 모드에서 수동 전체 동기화

### 2) 결제(PG)

- 요구:
    - .NET 8 + WPF 지원 SDK 확인
    - 카드리더기(USB/Serial) 드라이버/SDK 확인
- 플로우:
    - (앱) 결제 요청 생성 → (PG) 승인 → (앱) 승인 결과 수신
- 타임아웃:
    - 60초(설정 가능)
- 실패/취소:
    - 승인 취소(가능하면) API 호출

### 3) 프린터(ESC/POS)

- 기능:
    - 영수증 출력(텍스트 + QR(선택))
    - 재출력
- 오류:
    - 용지 없음/연결 끊김 감지 후 사용자 안내 + 관리자 로그

### 4) 주소 입력(선택)

- 우편번호/주소 검색 API(국내: 도로명주소 API 등) 연동 가능
- 오프라인 시 수기 입력만 허용

### 5) 3D 에셋 로딩

- 로더:
    - glTF(.glb) 로딩 파이프라인 정의
    - 에셋 경로: 로컬(Resources/Models3D) + 서버 다운로드(확장)
- 캐시:
    - 자주 쓰는 에셋 로컬 보관
- 버전:
    - 에셋 버전 불일치 시 강제 갱신 옵션

## 로깅/모니터링

- Serilog Sink:
    - 로컬 파일(필수)
    - 서버 전송(확장)
- 필수 로그 이벤트:
    - 화면 전환
    - 부품 선택/교체
    - 호환성 오류 발생
    - 결제 시작/성공/실패
    - 주문 생성 성공/실패
    - 프린터 오류
