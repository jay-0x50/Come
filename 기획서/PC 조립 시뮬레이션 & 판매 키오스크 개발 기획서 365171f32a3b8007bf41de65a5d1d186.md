# PC 조립 시뮬레이션 & 판매 키오스크 개발 기획서

## 1. 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 프로젝트명 | PC Builder Kiosk (가칭) |
| 플랫폼 | Windows 10/11, 터치스크린 키오스크 |
| 개발 프레임워크 | .NET 8, WPF |
| 아키텍처 패턴 | MVVM (Model-View-ViewModel) |
| 대상 사용자 | 매장 방문 고객 (비전문가 포함) |
| 핵심 가치 | 부품 선택 → 3D 조립 시각화 → 만족 → 결제 → 배송 |

---

## 2. 핵심 사용자 플로우

```
[시작 화면 / Attract Screen]
        ↓ 터치
[카테고리 선택] CPU / 메인보드 / RAM / GPU / SSD·HDD / 파워 / 케이스 / 쿨러
        ↓            ↖
        │        [상단 고정 검색 바] 이름 검색 / 태그(#CPU #GPU 등) 필터 → 검색 결과 화면
        ↓
[부품 선택 화면] (호환성 체크 포함)
        ↓
[3D 조립 뷰어] - 실시간 조립 시각화, 회전/줌/부품별 하이라이트
        ↓
[견적 요약 화면] 총 가격 / 예상 성능 / 소비전력 확인
        ↓
[배송지 입력]
        ↓
[결제 화면] (카드/간편결제 연동)
        ↓
[주문 완료 / 배송 안내]
```

## 3. 기능 요구사항

### 3.1 필수 기능 (MVP)

- [ ]  대기 화면(Attract Mode) - 일정 시간 미조작 시 자동 복귀
- [ ]  부품 카테고리별 목록 조회 (이미지, 스펙, 가격)
- [ ]  **부품 검색 기능 (필수)**
    - 이름 기반 검색 (자동완성, 오타 허용 수준의 유사 검색)
    - 태그 기반 필터링 (예: #CPU, #GPU, #DDR5, #게이밍, #고사양 등)
    - 카테고리 + 태그 + 키워드 다중 조건 조합 검색
    - 검색 결과 내 정렬(가격순/인기순/성능순) 및 재검색
    - 화면 어디서든 접근 가능한 상단 고정 검색 바(Global Search Bar)
- [ ]  부품 상세 정보 팝업 (스펙 표, 리뷰 요약 등)
- [ ]  부품 호환성 검증 로직
    - CPU ↔ 메인보드 소켓 매칭
    - RAM 규격(DDR4/DDR5) 매칭
    - 파워 용량 vs 전체 소비전력 검증
    - 케이스 크기 vs 메인보드 폼팩터(ATX/mATX/ITX) 매칭
    - GPU 길이 vs 케이스 내부 공간 매칭
- [ ]  선택 부품 실시간 견적 계산 (합계, 부가세, 할인)
- [ ]  3D 조립 뷰어
    - 부품 선택 시 해당 파츠 3D 모델 케이스에 순차 조립 애니메이션
    - 마우스/터치 드래그 회전, 핀치 줌
    - 부품별 클릭 시 하이라이트 + 정보 표시
- [ ]  장바구니(견적서) 저장 및 불러오기
- [ ]  배송지/연락처 입력 폼 (유효성 검사 포함)
- [ ]  결제 모듈 연동 (카드 리더기 / QR 간편결제)
- [ ]  주문 완료 화면 + 영수증 출력(프린터 연동)
- [ ]  관리자 모드 (부품 재고/가격 관리, 로그 조회)

### 3.2 선택 기능 (확장)

- [ ]  사전 구성 세트(게이밍용/사무용/영상편집용) 템플릿 추천
- [ ]  AI 기반 예산별 자동 견적 추천
- [ ]  AR/실물 크기 미리보기
- [ ]  다국어 지원 (한/영/중/일)
- [ ]  회원 로그인 및 주문 이력 조회

### 5.1 계층 책임

- **View**: XAML, 코드비하인드 최소화(이벤트 → Command 바인딩)
- **ViewModel**: 화면 상태/커맨드 관리, Service 호출, Model 가공
- **Model**: 순수 데이터 구조 (POCO)
- **Service**: 비즈니스 로직, 외부 연동(결제/DB/프린터/3D 로더) 캡슐화
- **Navigation**: INavigationService를 통한 화면 전환 (ViewModel 간 결합 제거)

## 7. 데이터 모델 설계 (요약)

### PartItem

```
- Id: string
- Category: PartCategoryType (Cpu, Mainboard, Ram, Gpu, Storage, Psu, Case, Cooler)
- Name: string
- Manufacturer: string
- Price: decimal
- Stock: int
- SpecJson: string          // 카테고리별 상이한 스펙 (JSON)
- ImageUrl: string
- Model3DPath: string        // 3D 에셋 경로
- PowerConsumptionW: int?
- Tags: List<string>         // 예: ["CPU", "인텔", "고사양", "게이밍"]
- SearchKeywords: string      // 이름 검색 최적화용 정규화 문자열(공백/특수문자 제거, 소문자화)
```

### PartTag

```
- TagId: string
- TagName: string            // 예: CPU, GPU, DDR5, 게이밍, 사무용, 고사양
- TagGroup: TagGroupType      // Category(부품군) / Spec(규격) / UseCase(용도)
```

### CompatibilityRule

```
- SocketType (CPU ↔ Mainboard)
- RamType (DDR4/DDR5)
- FormFactor (ATX/mATX/ITX)
- MaxGpuLengthMm
- MaxCoolerHeightMm
- RequiredPsuWattage
```

### BuildConfiguration

```
- SelectedParts: Dictionary<PartCategoryType, PartItem>
- TotalPrice: decimal
- TotalPowerConsumption: int
- IsCompatible: bool
- CompatibilityMessages: List<string>
```

### Order

```
- OrderId: string
- BuildConfiguration
- Customer (Name, Phone, Address)
- PaymentResult
- OrderStatus (결제완료/배송준비/배송중/완료)
- CreatedAt: DateTime
```

## 8. 호환성 검증 로직 (개발 우선순위 상)

1. CPU 소켓 ↔ 메인보드 소켓 일치 여부
2. RAM 규격(DDR4/DDR5) ↔ 메인보드 지원 규격 일치 여부
3. 메인보드 폼팩터 ↔ 케이스 지원 폼팩터 일치 여부
4. GPU 길이 ↔ 케이스 최대 GPU 장착 길이
5. 쿨러 높이 ↔ 케이스 최대 쿨러 높이
6. 전체 소비전력 합산 ↔ 파워 정격 용량 (여유율 20% 권장)
7. 미충족 시: 3D 뷰어 내 해당 부품 경고 하이라이트(빨간색) + 안내 메시지 출력

## 9. 검색 기능 상세 요구사항 (필수)

### 9.1 이름 검색

- 검색창 입력 시 실시간(디바운스 300ms) 자동완성 목록 노출
- 한글 초성 검색 지원 (예: "ㄹㅇㅈㅋㄴ" → "라이젠")
- 오타/유사어 허용 수준의 유사도 검색 (Levenshtein 기반 또는 Full-Text Search)
- 검색어 하이라이트 표시

### 9.2 태그 기반 필터링

- 태그 그룹 분류
    - **부품군 태그**: #CPU, #메인보드, #RAM, #GPU, #SSD, #HDD, #파워, #케이스, #쿨러
    - **규격 태그**: #DDR5, #DDR4, #AM5, #LGA1700, #ATX, #mATX, #ITX, #NVMe
    - **용도 태그**: #게이밍, #사무용, #영상편집, #고사양, #가성비, #저소음
- 다중 태그 동시 선택(AND/OR 조건 토글) 가능
- 선택된 태그는 칩(Chip) 형태로 상단에 표시, 개별 해제 가능
- 태그 클릭 시 즉시 PartListView/SearchResultView에 반영

### 9.3 통합 검색 동작

- 키워드 + 태그 + 카테고리 조합 검색 지원
- 검색 결과 없음(No Result) 시 유사 태그/인기 부품 추천 노출
- 정렬 옵션: 가격 낮은순/높은순, 인기순, 성능(벤치마크)순
- 검색 결과에서 바로 부품 상세 팝업 진입 및 견적에 추가 가능
- 검색 이력(최근 검색어) 로컬 저장 및 추천

### 9.4 관련 컴포넌트

| 구분 | 내용 |
| --- | --- |
| View | SearchBarView(전역 상단 고정), SearchResultView |
| ViewModel | SearchBarViewModel, SearchResultViewModel |
| Service | ISearchService (이름 검색 + 태그 필터 + 정렬 로직) |
| Model | PartTag, PartItem.Tags, PartItem.SearchKeywords |
| Data | 부품-태그 매핑 테이블(N:M), 태그 마스터 테이블 |

## 10. 3D 조립 뷰어 상세 요구사항

- 카메라: 마우스 드래그/터치 드래그로 궤도 회전(Orbit), 핀치/휠 줌
- 조립 순서: 케이스 → 파워 → 메인보드 → CPU → 쿨러 → RAM → GPU → 스토리지 순으로 애니메이션 삽입
- 부품 미선택 시 반투명 고스트 모델로 위치 표시
- 부품 교체 시 기존 파츠 제거 애니메이션 → 신규 파츠 삽입 애니메이션
- 성능 고려: LOD(Level of Detail) 적용, 저사양 키오스크 PC 대응
- 3D 에셋 포맷: glTF(.glb) 권장 (경량, 텍스처 포함 용이)

---

## 11. 결제/배송 연동 요구사항

- 결제 수단: 신용카드(IC카드 리더기), 간편결제 QR(카카오페이/네이버페이 등)
- 결제 프로세스: 견적 확정 → 결제 요청 → PG 승인 응답 대기(타임아웃 처리) → 성공/실패 분기
- 결제 실패 시 재시도 및 취소 로직 필수
- 결제 성공 시 주문 데이터 서버 전송 + 영수증 출력
- 배송: 주문 데이터를 물류 API 또는 사내 배송 시스템에 전달, 배송 상태 코드 수신

## 12. 키오스크 특화 요구사항

- 전체화면 Kiosk 모드 고정 (Alt+F4, 작업 전환 차단)
- 일정 시간(예: 60초) 미입력 시 자동으로 초기 화면 복귀 + 진행 데이터 초기화
- 터치 최적화 UI (버튼 최소 크기 48x48px 이상, 큰 폰트)
- 네트워크 단절 대비 로컬 캐시 및 오프라인 안내 화면
- 오류 발생 시 관리자 알림(로그 서버 전송) 및 고객 친화적 에러 메시지 노출
- 원격 유지보수를 위한 로그 수집/전송 체계
